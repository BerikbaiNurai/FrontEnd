This project is a simple blog made with Next.js using both Server-Side Rendering (SSR) and Static Site Generation (SSG). The home page shows the latest posts and is built with SSG using Incremental Static Regenaration (ISR) to update every 60 seconds. Each blog post has a dynamic page gereated with SSG and uses fallback: "blocking" to add new posts without rebuilding. The user profile page uses SSR to fetch data on every request. Data and types are defined in lib/api/ts and types/index.ts. This project helps understand when to use SSR for dynamic content and SSG for faster static pages. AI pages render correctly and follow the Next.js rendering strategies.
