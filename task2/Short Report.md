React is a JS library that works as the view layer in web applications. This means React focuses only on showing the user interface (UI) based on data. Components are like small parts of the UI. They take data, called state, and show it on the screen. For example, in our lab, the Counter component uses the useState hook to stire the current number. React doesn't manage backend data, routing, or storage - it only handles how the UI looks.
When a user clicks the "Increment" or "Decrement" button the state changes. React notices this change and automatically re-renders the component. Re-rendering means React updates only the part of the UI that changes without reloading the whole page. Using function components and hooks like useState, we can make the interface respond to user actions easily.
React uses a virtual DOM to make updates fast. The virtual DOM is a copy of the real DOM. When state changes, React compares the new virtual DOM with the previous one and finds the differences. Then it updates only the necessary parts in the real DOM. This process is called diffing and patching, and it makes React application efficient. In this lab, we set up the project using Vite as described in Ch1, then created the Counter component and rendered it in App.jsx. This demonstrates how React manages state and automatically updates the view, showing that React is just the view layer.
