Lab11.2:  Lists, Navigation, and Platform-Specific Code

Description: A product catalog app where users can view products and open a detailed screen for each item.

Features: Product list using FlatList. Navigation between screens. Product detail view. Passing data via navigation.

Technologies: React Native, Expo, TypeScript, React Navigation, FlatList.

Learning Outcomes: Working with lists in React Native. Screen navigation. Component structure organization. Building multi-screen mobile apps.
