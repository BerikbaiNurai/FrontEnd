Lab 13.2 - Bottom Tab Navigation

Description: In this lab I created bottom tab navigation using React Navigation. The app has 4 tabs: Home, Search, Notifications, Profile. Each tab has its own stack navigation.

Features:
Bottom tab navigation
Icons using Ionicons
Badge for notifications
Stack inside tabs
Navigation between screens

How it works: Tab.Navigator controls main navigation. Each tab uses Stack.Navigator for screens. Example: Home - Profile - Settings.

What I learned: How to use Tab Navigator. How to combine Stack and Tab navigation. How to use icons and badges.
